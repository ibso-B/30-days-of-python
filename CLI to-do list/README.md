# Day 2: Python CLI To-Do List

## About the Project

This is a command-line to-do list application built with Python. It allows users to manage tasks directly from the terminal.

## Features

- Add new tasks.
- Display all tasks.
- Mark tasks as completed.
- Delete tasks.
- Save tasks in a JSON file.

## Technologies Used

- Python
- JSON
- Git and GitHub

## How to Run

Make sure Python is installed on your computer.

### Add a task

```bash
python todo.py add "Buy notebook"
```

### List tasks

```bash
python todo.py list
```

### Mark a task as completed

```bash
python todo.py done 1
```

### Delete a task

```bash
python todo.py delete 1
```

## Data Storage

Tasks are stored in `tasks.json`, which is created automatically when a task is added.
